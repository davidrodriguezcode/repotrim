Licensing & Verification

RepoTrim uses a serverless licensing system backed by Google Firebase. This setup authenticates CI/CD runners, build servers, and local command-line users dynamically with minimal latency. High-performance caching layers keep response windows below 3 seconds.

Activation Models

Licenses are checked on startup using the environment variable REPOTRIM_LICENSE_KEY. You can acquire a license through two primary pathways:

  • Option A (Automated): Secure purchases via Stripe checkout instantly provision and save active keys to the central Firestore repository.
  • Option B (Manual): Developers can seed keys manually in the Firestore console under the licenses collection.

Verification API Reference

Outbound validation requests are processed through our custom endpoint. The gateway accepts JSON payloads over HTTPS POST requests.

POST https://api.repotrim.innsoftlabs.com/v1/verify

Request Headers

Content-Type: application/json
Authorization: Bearer <license_key>

Request Body Payload

{
  "license_key": "rt_live_dbe6ff3b1396c7659145d9f5929d73fe"
}

Success Response (HTTP 200)

{
  "valid": true
}

Error Responses

  • HTTP 400 Bad Request: Key missing or format error.
  • HTTP 402 Payment Required: License subscription expired.
  • HTTP 403 Forbidden: Key was suspended, revoked, or not found in the database.

Stripe Webhook Integration

Stripe automated key generation is supported via the hosted webhook. The webhook parses raw requests, checks cryptographic signatures, and provisions licenses automatically.

Stripe Dashboard Configuration

Under your Stripe Dashboard developers section, add a new Destination with the following properties:

  • Destination URL: https://api.repotrim.innsoftlabs.com/stripe-webhook
  • Version: Latest Stable
  • Event Subscriptions: checkout.session.completed

Security Warning: Always verify webhook signatures inside the handler using the STRIPE_WEBHOOK_SECRET. The webhook signature is delivered in the HTTP Header Stripe-Signature and prevents request spoofing.

CLI Integration Guide

Incorporate RepoTrim into your local terminals and CI/CD pipelines by setting the environment variable before calling the binary.

1. Local Environment Setup

Add the following environment variable to your terminal session or shell configuration (.bashrc or .zshrc):

export REPOTRIM_LICENSE_KEY="rt_live_..."
./repotrim -dir .

2. Github Actions CI/CD Pipeline

Add your license key as a repository secret (REPOTRIM_LICENSE_KEY) and reference it in your workflow file:

- name: Run RepoTrim Asset Scan
  run: ./repotrim -dir .
  env:
    REPOTRIM_LICENSE_KEY: ${{ secrets.REPOTRIM_LICENSE_KEY }}

3. Developer Offline Bypass

For testing, development environments, and unit testing pipelines, you can use the hardcoded offline bypass key without needing network access:

export REPOTRIM_LICENSE_KEY="TEST_LICENSE_KEY"
./repotrim -dir .
